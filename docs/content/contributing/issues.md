# Bonds | Contributing | Reporting Issues

Bug reports, feature requests, and workflow discussions are all welcome.

## Bug reports

Please include as much relevant detail as possible:

- what you expected to happen
- what actually happened
- steps to reproduce
- operating system and environment details
- relevant logs, error messages, or screenshots
- whether the issue affects the CLI, core library, app, or docs

The faster someone can reproduce the problem, the faster it can usually be fixed.

## Feature requests

When requesting a feature, please describe:

- the problem you are trying to solve
- the workflow you have in mind
- why it fits Bonds specifically
- which surface it affects: core, CLI, app, or docs

For larger ideas, referencing the existing roadmap helps keep the conversation grounded in the current direction of the project.

## Discussions before larger work

If you are planning a larger feature, refactor, or workflow change, opening an issue or discussion first is appreciated.

That helps confirm:

- whether the change fits the roadmap
- where the implementation should live
- whether there are known constraints or related work already in progress

## Security issues

If you believe you have found a security issue:

- follow the guidance in [Security Policy](../resources/security.md)
- avoid posting sensitive exploit details publicly
- for serious issues, contact the maintainers directly at [contact@mjanglin.com](mailto:contact@mjanglin.com)

## Community expectations

By participating in this project, you agree to follow the [Code of Conduct](../resources/code-of-conduct.md).
