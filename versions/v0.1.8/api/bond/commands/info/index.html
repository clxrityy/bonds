cmd_info
Command handler for the info command, which displays detailed information about a specific bond identified by its ID. The command retrieves the bond from the bond manager, and if found, it prints out the bond’s ID, source path, target path, creation timestamp, and any associated metadata. It also checks the status of the bond’s target (whether it exists and is a symlink) and provides a status message indicating whether the bond is healthy, broken, or in a warning state. If the bond cannot be found or an error occurs during retrieval, it returns an appropriate error message to the user. Example usage:
