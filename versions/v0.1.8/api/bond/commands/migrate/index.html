cmd_migrate
Migrate command handler, which moves the target of a bond to a new location. The command retrieves the bond by its ID or name, resolves the destination directory (either from the provided argument or from the default configuration), and constructs the new target path by preserving the basename of the existing target. If the bond is already at the destination, it informs the user and exits without making changes. Otherwise, it delegates to the bond manager’s update_bond method to handle the migration, which includes updating symlinks and the database record.
